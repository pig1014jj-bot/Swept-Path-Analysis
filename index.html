關於 Swept Path Studio

專業建築道路與多軸重型起重機轉彎車跡模擬

專為建築、土木工程及吊裝道路動線規劃設計的車輛掃掠軌跡 (Swept Path Analysis) 檢討工具。

支援直接匯入 AutoCAD .DXF、高解析向量 PDF 與點陣圖，並可直接導出 AutoCAD R12 格式 DXF 實體軌跡線與車體印記。

內建 Tadano / Demag AC 6.300-1 六軸 300 噸級全地形吊車的官方 CAD 旋回幾何與 R1～R4 標註線，支援多軸協同轉向與圓導角（Fillet Arc）即時平滑過度。
